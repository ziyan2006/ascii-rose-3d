# 字符玫瑰 · 点云版

用字符画出的 3D 玫瑰。每个采样点是一个字符，位置和大小由**真 3D 投影**决定，
亮度由**逐点法线**与固定光源的点积决定，配合轻微辉光。

这是"字符画系列"的第一版，追求**立体感和发光质感**。

## 运行

需要一个本地 HTTP 服务（ES module 不能用 `file://` 打开）：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 交互

- **拖拽**：旋转玫瑰，松手带惯性
- **URL 参数**：`points`、`chars`、`sensitivity`、`inertia`

## 技术要点

- 参数曲面生成玫瑰几何（花瓣、茎、叶），逐点法线由几何直接给出，不从深度图求
- WebGL 优先渲染，失败自动回退到 Canvas 2D（`createRenderer`）
- 性能自适应：帧率不足时降低采样点数，有下限保护
- **运行时零网络请求**：不加载任何外部资源，字体和图标都是内联的

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面、样式、控制条 |
| `geometry.js` | 玫瑰几何与法线生成 |
| `renderer.js` | WebGL / Canvas 2D 渲染器 |
| `app.js` | 交互、惯性、性能自适应 |
